# Study Tape · 学时

基于用户提供的《2026–2027 学生校历》，无后端、无构建依赖的中文网站。

## 本地启动

```sh
npm start
```

打开 http://127.0.0.1:4173 。测试：`npm test`。

## 计算规则

- 学费提供 93,000 元、99,000 元及自定义金额三个选项，不绑定入学年份或年级。默认选择 93,000 元，可按实际年学费修改。
- 按用户选择，仅教学、复习及考试工作日计费。默认从正式开学日 2026-09-07 起算，至第二学期考试最后一天 2027-06-11，共 157 个在校日（第一学期 81 天，第二学期 76 天）。结束日期含当天，可在原校历范围内修改。
- 每秒费率 = 年学费 ÷（在校日数 × 24 × 3600），非在校日自动暂停。排除周末、校历所标中秋节、国庆阶段、圣诞关闭日、元旦、清明节、劳动节关闭日及端午节；注册迎新及冬夏学校不计费。毕业典礼不额外扣除。默认不含补考，若结束日延长到 2027-08-06，则补考复习与补考共增加 15 天。关闭网页后仍按实际经过的有效在校时间恢复。
- 专注计时按真实时间差恢复，暂停不计专注时间，番茄钟后台超时按预设时长封顶。专注时间与在校计费日求交集后才计时间价值，非计费日仍可学习但价值金额为 0。设置修改不改变进行中专注的费率及日期范围；每条记录保留当时规则。
- 日期、专注记录及运行中的计时器保存在当前浏览器 localStorage。没有跨设备同步。最多保留 5,000 条记录，可导出 CSV；跨午夜的专注按时间区间拆算今日统计。
- 校历按有效计费工作日着色，周末及指定假日单独排除，校历原件保存在 `dist/assets/academic-calendar-2026-27.pdf`。这里将学校收费换算为时间成本，并非真实扣款。

部署资源在 `dist/`，静态托管配置在 `.openai/hosting.json`。数字字体 Barlow 随网站本地提供，许可证见 `dist/assets/barlow-license.txt`。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`。在 GitHub 仓库的 Settings → Pages 中选择 GitHub Actions 后，推送 main 分支会运行测试并发布 `dist/`。所有资源使用相对路径，兼容仓库子路径。
